# 🍼 Baby Card Matching Memory Game 
A browser-based memory matching game where players flip cards to find matching pairs of baby-themed emojis. The game features randomized card placement, visual feedback for matched pairs, and a restart option to play again.

## Features
- 10 cards featuring 5 matching emoji pairs
- Randomized card placement with each new game
- Click-to-reveal card interaction
- Matched cards remain face up
- Non-matching cards flip back after a short delay
- Restart button to shuffle and start a new game
- Responsive layout for different screen sizes
  
## Tech Stack
- HTML
- CSS
- JavaScript 

## Getting Started
1. Clone the repository:
```
git clone https://github.com/CarlyJovon/card-matching-memory-game.git
```

2. Navigate to the project directory:
```
cd card-matching-memory-game
```

3. Open `index.html` in your browser to start playing.

No additional dependencies or installation required.

## How to Play
1. Click any card to reveal its emoji.
2. Select a second card to find its matching pair.
3. Matching pairs remain face up and non-matching cards flip back after one second.
4. Select Restart to shuffle the cards and begin a new game.
